Admin key required. This sandbox was installed with an ADMIN_KEY, so the admin API is protected. Paste the key into the key box at the top right, then press Enter.
Where do I find it?

The installer printed it once, and it is the ADMIN_KEY line of the .env file in your install folder:

Windows   %LOCALAPPDATA%\SapBahSandbox\.env
macOS     ~/Applications/SapBahSandbox/.env
Linux     ~/.local/share/sap-bah-sandbox/.env
Server    /opt/sap-bah-sandbox/.env

On a trusted LAN you can turn the check off instead: blank out ADMIN_KEY in that file and restart (sapbah restart). Do not do that if the sandbox is reachable from the internet.
